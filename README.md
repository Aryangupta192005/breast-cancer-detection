# Breast Cancer Detection System

A Machine Learning project to classify whether a tumor is benign or malignant using medical diagnostic data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## ML Models Used
- Logistic Regression
- Decision Tree
- Random Forest Classifier

## Features Used
- Radius
- Texture
- Perimeter
- Area
- Smoothness
- Other diagnostic features

## Objective
To build a machine learning classification model for breast cancer detection and compare multiple algorithms.

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Classification Report
